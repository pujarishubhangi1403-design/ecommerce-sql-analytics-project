# E-Commerce SQL Analytics Project

## Project Overview

This project analyzes customer purchasing behavior,
revenue trends, and product performance using SQL Server.

## Tools Used

- SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

## Database Schema

4 relational tables:

1. Users
2. Orders
3. Order_Items
4. Products

## Business Questions Solved

- Total Revenue Generated
- Top Spending Customers
- Best Selling Products
- Average Order Value
- Monthly Revenue Trends
- Customer Lifetime Value
- Customer Retention Analysis

## Key Insights

Generated ₹1.19 Crore in total revenue analyzed across 4,021 completed orders
Top 10 customers contributed ~2.46% of completed order revenue, identified for VIP retention targeting
Willow Result generated the highest product revenue (₹73,500+); Pulse Money led in order volume with 38 purchases
Average Order Value was ₹601.77, establishing a baseline KPI for upsell strategy
